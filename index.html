Digite qualquer palavra, sem precisar de acento. Clique num código para copiar. / volta para a busca · Esc limpa.
Aba Ações — para descobrir onde e como distribuir.
  • Digite o que a parte quer na busca (ex.: despejo, divórcio, maria da penha, inventário). Pode digitar várias palavras: dano moral banco.
  • Use os botões de competência e de sistema para filtrar. Sem nada digitado, aparecem os casos mais comuns (★).
  • Também dá para buscar pelo número da classe ou do assunto (ex.: 93, 060503, 7779).
  • Clique em qualquer código (classe ou assunto) para copiar e colar direto no sistema.
  • Os códigos de assunto vêm com etiqueta: EPROC (azul) é o código para lançar no eproc; CNJ (roxo) é o código usado no DCP, PJe e SEEU.
  • Quando a ação diz “usar o assunto do crime/ato” ou “conforme o pedido”, clique em Procurar assunto para abrir a aba Assuntos.

Aba Assuntos (códigos) — a tabela única de assuntos (CNJ × eproc × DCP).
  • Digite o código CNJ (ex.: 7779), o código do eproc (ex.: 060503) ou parte do nome (ex.: furto).
  • Mostra se o assunto pode ser lançado no eproc e em quais competências está ativo no DCP.
Aba Bairros — para descobrir para qual fórum/juizado vai, conforme o bairro.
  • Digite o bairro (ex.: meier, bangu, ilha) e clique nele. Aparecem as competências que mudam de bairro para bairro; as que são sempre na Capital ficam resumidas embaixo.
  • Escolha uma competência nos botões do topo (ex.: Família) para deixá-la em destaque. Ela continua destacada quando você troca de bairro.
  • Com uma competência escolhida e nenhum bairro, aparece a lista inversa: quais bairros vão para cada fórum.
  • “Bairro dividido” quer dizer que o bairro é atendido por mais de um juizado — depende da rua.
